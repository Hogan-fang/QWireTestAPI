# QWireTestAPI Blueprint

## Overview

`QWireTestAPI` is the concrete API test project built on top of `QWireCore`.
Its purpose is to organize test scenarios, test data, assertion extensions, and execution assets for API validation.

## Scope

- API test case organization
- Test data and environment configuration
- Custom assertion extension integration
- TestNG-based execution and reporting

## Document Index

- `implementation-plan.md`: project-level execution and build plan
- `schema/`: structural definitions for test data, config, and case layout
- `spec/`: behavioral definitions for test scenarios, assertions, and execution expectations
